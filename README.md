# NOVA VAULT

Sistema de subastas virtual desarrollado con Flask y MySQL.

## Características

### Administrador
- Crear subastas
- Editar subastas
- Eliminar subastas
- Administrar ofertas

### Comprador
- Registro e inicio de sesión
- Ver catálogo
- Seguir subastas
- Realizar ofertas
- Pago de productos ganados
- Generación de comprobante

## Tecnologías

- Python
- Flask
- MySQL
- HTML
- CSS
- GitHub
